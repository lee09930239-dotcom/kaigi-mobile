# 会議字幕 PC 版(お客様向け)の一鍵更新

お客様の PC の会議字幕ツールは、起動時に `pc/version.json` を読み、`build` が自分より新しければ「今すぐ更新」ボタンを出します。
押すと `pc/meeting.py` をダウンロードして入れ替え、再起動します。

- **main にマージした時点で全お客様に配信されます。** 新版を出すときは `meeting.py` の `BUILD` と `version.json` の `build` を同じ値(日付+英字、例 `2026-12-01a`)に上げてください。値は文字列比較なので必ず大きくなるように。
- `BUILD` が一致しない・文法エラーのあるファイルはツール側で拒否されます。
- 前の版はお客様 PC の `backup/meeting_<版>.py` に残ります。
